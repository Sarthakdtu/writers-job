# 2026-09-05

## Plans

- **Mobile / PWA migration plan** (`plans/mobile-pwa-migration.md`, design only, not
  implemented). Analyzes hosting the local-first backend for phone access: recommends
  Strategy A (serve the existing backend + built frontend from a LAN/self-hosted HTTPS
  origin the phone PWA connects to), followed by a responsive/touch pass and offline
  caching. Explicitly keeps the phone shell a pure PWA (no native app).

## Features

- **Remove chapter cover art for good.** New `DELETE .../chapters/{ch_id}/art` route
  clears the chapter's `image_url` and deletes its local asset file
  (`FileManager.clear_chapter_image_url`). Book Outliner chapter-card thumbnails get a
  hover trash overlay; the Draft Editor gets a "Remove Art" button beside "Cover Art".
