# 2026-09-06

## Features

- **Ability blocks + filters in Magic & Mechanics.** Mechanics ("abilities") now render as
  compact blocks instead of large cards, with dropdown filters over **Magic System** and
  **Technology Level** (built from existing entries) and a result count. Clicking a block
  opens a **detail modal** showing the full entry (image, magic system, tech level, global
  rules, linked characters) with Edit/Delete actions.
- **Images for abilities.** `WorldMechanics` gains an optional `image_url`; the mechanics
  form now supports upload (local `/assets/`) or URL, and thumbnails show on blocks + detail modal.
- **Cross-referential character links for abilities.** Ability blocks and the detail modal now
  show circular character avatars (overlapping stack, up to 3 + overflow count). The detail modal
  has an Add/Remove picker that edits the linked characters' `mechanic_ids` (POST `/characters`)
  so changes instantly reflect on the character profiles, mirroring the artifact→character sync.
- **Characters on Factions & Guilds.** `Faction` gains `member_ids[]` (character ids).
  The faction card shows an overlapping avatar stack of members (up to 3, then `+N`), with
  direct remove-on-click and an edit button that opens the faction form with a character
  multi-select picker. Deleting a character now also strips its id from every faction's
  `member_ids`.
- **Cross-referential Factions tab in Character Roster.** The character profile gains a
  "Factions" detail tab (plus a summary stat) listing the factions/guilds the character
  belongs to, with a join/leave dropdown. `Faction.member_ids` is the single source of
  truth, so membership edited here or in the Worldbuilding faction cards stays in sync.

## Bugs

- **Note reference tooltips only on hover.** In the Character Roster Notes tab, each note
  card wrapper was classed `group`, which collided with the entity reference's own `group`
  (used for its `group-hover:block` tooltip). Because an ancestor `group` was hovered, every
  `[[type:id|label]]` reference in a note lit up its tooltip at once. The note wrapper now
  uses a named group (`group/note` so edit/delete buttons still appear on card hover) and
  the reference tooltips only show when the reference itself is hovered, matching the
  chapter-outline behavior.
