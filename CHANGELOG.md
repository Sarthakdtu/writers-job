# CHANGELOG

> Entries are split by date into individual files under `CHANGELOG/`.
> See [CHANGELOG/INDEX.md](CHANGELOG/INDEX.md) for the full index.

## Convention

When making code changes:
1. Check if `CHANGELOG/YYYY-MM-DD.md` exists for today's date.
2. If it exists, append your entry to it.
3. If it doesn't exist, create it with a `# YYYY-MM-DD` header and add your entry.
4. Update `CHANGELOG/INDEX.md` if you created a new date file.

Keep entries concise — one bullet per feature/fix with a brief summary and key details.
